# 0001. Record architecture decisions

- Status: Accepted

## Context

This project is written by Claude across many sessions. Chat sessions are not a
durable or public record, so the reasoning behind decisions must live in the
repository.

## Decision

Record each significant decision as a numbered ADR in `docs/adr/`, using the
structure of this file: status, context, decision, consequences. Superseded
ADRs stay in place with their status updated.

## Consequences

- Reviewers and future sessions can see why the project is shaped as it is.
- Pull requests that change a recorded decision must add a superseding ADR.
